# Watch Drill

Unofficial study drill for the **2026 LAPD Police Lieutenant (2232)** list.

This is a personal study aid. It is not Personnel, not the Department, and not an official answer key. Verify anything that matters against the current public bibliography and the current Manual.

Live use while stores are in review: turn this folder into a GitHub Pages site and send the `https://YOURUSER.github.io/watch-drill/` link. iPhone users open that link **in Safari**, then Share → Add to Home Screen.

## What is in here

- `index.html` — the full app and question bank
- `icon.png` — home-screen / tab icon

Written mode deals a random set, then **Next random set** skips cards already seen this sitting until the list is used up.

## Put it on GitHub Pages (about two minutes)

1. Go to [https://github.com/new](https://github.com/new)
2. Repository name: `watch-drill`
3. Public
4. Create repository
5. On the empty repo page: **uploading an existing file**
6. Drop `index.html` and `icon.png` (and this README)
7. Commit
8. **Settings → Pages**
9. Source: **Deploy from a branch**
10. Branch: `main`, folder: `/ (root)`
11. Save
12. Wait one minute. The site URL is:

`https://YOURUSER.github.io/watch-drill/`

Send that URL. Do not send the zip to iPhone users.
